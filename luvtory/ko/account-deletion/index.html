럽토리 계정 및 데이터 삭제 요청

안내 갱신일: 2026-09-26 · 정식 출시 날짜 미정

앱을 삭제했거나 로그인할 수 없어도 support.runpet@gmail.com으로 럽토리 계정 삭제를 요청할 수 있습니다. 아래 버튼은 이메일 작성 창을 엽니다. 이메일 앱이 없으면 주소를 복사해 웹메일에서 보내세요. 이 페이지를 이용하기 위해 앱을 다시 설치하거나 로그인할 필요는 없습니다.

이메일로 요청하기

제목을 ‘럽토리 계정 삭제 요청’으로 하고, 사용한 로그인 방식(Apple 또는 Google), 회신 가능한 연락처, 계정과 연결된 데이터의 삭제를 원한다는 의사를 알려주세요. 계정을 찾는 데 필요한 추가 정보는 담당자가 최소한으로 안내합니다.

비밀번호, 로그인 인증 코드·토큰, 카드번호, 전체 결제 영수증, 신분증 사본이나 상대방의 비공개 사진은 보내지 마세요. 이메일 발송은 삭제 요청의 접수이며, 즉시 삭제 완료를 뜻하지는 않습니다.

본인 확인과 처리 결과

개인정보 보호책임자 박정현이 요청을 확인합니다. 발신 이메일 주소나 닉네임만으로 소유자를 확정하지 않으며, 등록된 로그인 정보·연락 수단에 근거한 안전한 본인 확인을 안내합니다. Apple의 이메일 가리기 주소와 문의를 보낸 주소가 다른 경우에도 이를 설명해 주세요.

접수, 본인 확인, 삭제 진행, 완료를 구분해 안내합니다. 다른 계정이나 상대방 개인 계정은 본인 계정 삭제 요청으로 삭제하지 않습니다. 안전한 확인이 어려우면 필요한 후속 절차를 안내하며, 구독 해지나 상대방의 승인을 데이터 삭제의 선행 조건으로 요구하지 않습니다.

앱 안에서 요청하기

로그인할 수 있다면 우리 > 우리 설정(톱니바퀴) > 내 계정 > 계정 및 데이터 > 계정 삭제를 선택하세요. 삭제 영향과 별도 구독 안내를 확인하고 Google·Apple 재인증을 진행합니다.

로그아웃이나 앱 삭제만으로 서버의 계정·기록이 삭제되지는 않습니다. 계정은 유지하고 일부 사진이나 기록만 삭제하려면 해당 기록의 삭제 기능을 사용하거나 이메일로 요청 범위를 알려주세요.

삭제되는 자료와 상대방에게 미치는 영향

계정 삭제는 본인의 럽토리 로그인 계정·프로필·가입 확인 및 약관 동의 기록(수집된 경우), 개인 지갑·보유 내역·거래 자료를 정리합니다. 현재 연결을 종료하고 현재·과거 관계에 연결된 공유 사진·앨범·추억·일정·기념일·함께하기 기록·타임캡슐과 음성을 삭제 처리합니다.

공유 자료는 누가 작성했는지와 관계없이 정리되므로 상대방이 올린 자료도 포함됩니다. 상대방의 개인 계정과 본인 구독은 유지합니다. 삭제된 공유 자료를 새 상대에게 넘기지 않으며 앱에서 되돌릴 수 없습니다. 이미 기기 밖에 저장·촬영한 사본까지 회수하지는 못합니다.

접근 종료와 서버 정리·실패 재시도·진행 중 업로드의 잔여 파일 정리는 단계적으로 진행됩니다. 계정 정리 완료와 모든 제공업체 백업 사본의 물리적 삭제는 같은 시각이 아닙니다. 접근 종료가 확인되면 앱의 사적 캐시와 위젯 표시용 자료도 비우고 갱신을 요청합니다.

별도로 남는 자료와 기간

영수증 재사용 방지용 최소 가명 표식은 탈퇴 처리 완료 후 1년을 기준으로 정기 정리합니다. 금액·통화가 담긴 거래 장부와는 별도이며, 스토어가 보관하는 결제 자료는 해당 스토어의 정책과 법적 의무를 따릅니다.

일반 문의는 처리 완료 후 1년, 비공개 신고 사건은 사건 처리 완료 후 1년 보관하는 기준입니다. 미해결 요청은 완료로 간주하지 않습니다. 법령이나 분쟁 처리로 별도 보존이 필요한 경우 필요한 항목·근거·기간을 구분합니다. 모든 자료를 무기한 남기거나 문의 접수만으로 즉시 제거한다고 정하지 않습니다.

미디어 저장소에는 파일 삭제 후 7일간 복구용 보존이 설정되어 있습니다. 앱 내 복원을 제공한다는 뜻은 아닙니다. 확인한 Cloud Logging 저장소의 보관은 일반 로그 30일, 필수 감사 로그 400일입니다. Firebase는 Crashlytics 자료를 90일 보관 후 제거하기 시작하고, 인증 사용자 삭제 후 잔존 자료를 운영·백업 시스템에서 180일 이내 제거한다고 안내합니다. 각 기간은 해당 종류의 자료에만 적용됩니다.

이메일 요청의 발신·회신 주소, 본문과 필요한 첨부는 일반 Gmail을 통해 접수·본인 확인·답변에 사용합니다. Google의 정보 처리·보관 설명도 확인할 수 있습니다. 불필요한 사적 자료는 보내지 마세요.

  • Firebase 데이터 처리·보관 안내
  • Google 개인정보 및 보관 안내

구독은 별도로 관리하기

계정·앱 삭제, 로그아웃이나 커플 연결 해제만으로 Apple·Google의 자동 갱신 구독이 해지되지는 않습니다. 구매한 스토어에서 자동 갱신 중단을 확인하세요. 구독 해지와 이미 결제한 금액의 환불은 별도 요청이며, 적용 법률이 보장하는 권리는 유지됩니다.

  • Apple 구독 취소 안내
  • Google Play 구독 취소 안내

Google·Apple 계정과의 차이

럽토리 계정을 삭제해도 Google 계정, Gmail 또는 Apple 계정 자체는 삭제되지 않습니다. Google·Apple에서 럽토리 로그인 연결만 해제하는 것은 럽토리 데이터 삭제 요청을 대신하지 않습니다.

앱 안에서는 Apple 재인증으로 얻은 인증 정보의 철회를 요청합니다. 앱 밖의 요청에서 필요한 인증 정보가 없다면 럽토리 데이터 삭제와 Apple 접근 권한의 직접 철회를 구분해 안내합니다. 로그인 토큰을 이메일로 보내거나 Apple 수동 철회를 먼저 완료해야만 데이터 삭제를 요청할 수 있는 것은 아닙니다.

  • Apple로 로그인한 앱 관리
  • Google 로그인 연결 관리
