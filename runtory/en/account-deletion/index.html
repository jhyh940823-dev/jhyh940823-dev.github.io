Account Deletion

Last updated: August 28, 2026

Request deletion in the app

Signed-in users can request deletion in Settings → Delete Account. On iOS, while the Firebase account is still available, RUNTORY first attempts the legacy deletion path for reachable pre-cutover CloudKit location-use fact records. The Firebase server must then durably accept the authenticated deletion request before the accepted deletion flow continues.

RUNTORY data deleted

  • the RUNTORY account in Firebase Authentication
  • account-scoped Cloud Firestore profile, Friends and structured-backup data
  • Cloud Storage for Firebase account-backup route and app-managed record-photo assets
  • account-scoped operational data and location-use fact records that server policy requires to be deleted
  • user-scoped local Drift data, routes, app-managed photos and game progress on this device
  • the legacy iOS deletion process for reachable pre-cutover CloudKit location-use fact records

Deletion order and retries

After the Firebase server durably accepts the deletion request, the app cleans the user's local scoped data. The server uses the durable deletion job to block remote access and continue physical deletion of Firebase backup, Friends, profile and account data. If network/server failures prevent immediate physical completion, the job remains retryable. A request that the server did not accept is not reported as deletion success.

Managed separately

  • App Store/Google Play subscriptions: not automatically cancelled by deleting the RUNTORY account; manage them separately in the applicable store.
  • Store-held payment/transaction records: may remain under the store's policies and legal obligations.
  • Device photo library: originals kept by the user in the system photo library are not deleted by RUNTORY account deletion.
  • OS location permission: managed separately in device settings.

Sign in with Apple / Google access

Deleting the RUNTORY account may not automatically remove the app connection shown in Apple or Google account settings. Users can manage RUNTORY access separately in the applicable connected-app/sign-in settings.
