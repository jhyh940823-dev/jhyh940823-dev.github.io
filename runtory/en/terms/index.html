RUNTORY provides outdoor/indoor running records, pet/egg/quest/challenge/badge/collection/inventory gameplay, Friends, Firebase-based account backup/restore, RUNTORY Plus and ads for free users. Outdoor GPS running requires the applicable location-service consent and OS location permission. Location processing may continue while an active run is backgrounded where the operating system permits.

Article 5 (Content and data)

Core data may be stored locally. Remote profile, Friends and structured account-backup data is processed in Cloud Firestore, while large backup assets such as precise completed-run routes and app-managed original record photos may be processed in Cloud Storage for Firebase. Friends uses friend codes, public display names, relations and weekly aggregates while excluding precise GPS routes, record photos, email and auth tokens from its current data contract.

Logging out does not delete all local data. Follow the app's ownership-protection/local-reset guidance when switching accounts.

Article 8 (Account deletion)

Signed-in users can request account deletion in Settings. On iOS, the app first attempts the legacy CloudKit deletion path for pre-cutover location-use facts. The Firebase server must then durably accept the authenticated deletion request before the accepted deletion flow proceeds. After acceptance, the app cleans user-scoped local data and the server continues deleting remote backup, Friends, profile and account data under the durable deletion job. Temporary network/service errors may remain retryable.
