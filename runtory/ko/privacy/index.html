제1조 (처리 목적)

런토리는 러닝 기록, 펫 성장, 친구, 계정 백업·복원, iOS 구독, 무료 이용자 광고와 백엔드 보안을 제공하기 위해 필요한 정보를 처리합니다. 현재 iOS 상용 버전은 Firebase Auth, Sign in with Apple, Firebase App Check, Google UMP 및 Google Mobile Ads를 사용합니다.

제2조 (처리 항목)

  • Firebase UID, 로그인 제공자 정보, 제공되는 경우 이메일·프로필 정보
  • 공개 표시 이름, 친구 코드·요청·관계·목록·랭킹 요약
  • 만 14세 이상 확인과 약관 동의 버전·시각
  • 앱·기기 무결성 확인을 위한 App Attest·DeviceCheck·App Check 관련 정보
  • 정밀 위치, 완료 러닝의 GPS 경로 좌표, 거리·시간·페이스, 모션·걸음 데이터
  • 사용자가 선택하고 앱이 관리하는 원본 기록 사진
  • 펫·알·챌린지·인벤토리·배지·설정과 구조화 백업 데이터
  • iOS 구독 상품, 거래 검증 자료, 자격 상태와 최소 거래 상관관계 정보
  • 광고 동의 상태와 광고 제공 과정에서 처리될 수 있는 IP 기반 대략적 위치, 앱·기기 식별 정보, 광고 데이터, 상품 상호작용 및 SDK 진단 정보

런토리는 결제 카드번호나 은행계좌 정보를 직접 수집·저장하지 않습니다.

제3조 (저장과 외부 처리)

앱 데이터는 기기 내 Drift/SQLite, SharedPreferences, 앱 문서 저장소에 저장됩니다. Firebase Auth는 로그인, Firebase App Check는 앱·기기 무결성, Firestore는 계정·프로필·친구·구조화 백업과 비공개 구독 자격, Firebase Storage는 계정별 완료 러닝 경로와 원본 기록 사진, Cloud Functions는 구독 검증과 계정 삭제 정리에 사용됩니다. Apple은 로그인·증명·App Store 결제를 처리합니다.

완료된 러닝 경로와 앱이 관리하는 원본 기록 사진은 계정별 Firebase Storage에 백업될 수 있습니다. Firestore에는 복원용 매니페스트가 저장되며 공개 다운로드 URL, 로컬 절대경로, 원시 좌표 배열과 이미지 바이트를 직접 저장하지 않습니다. 생성된 오버레이·결과 이미지, 지도 스냅샷과 공유용 내보내기 파일은 현재 백업 대상이 아닙니다.

개인정보의 국외 처리위탁

런토리의 Firestore 데이터베이스와 이용자 백업용 Firebase Storage는 대한민국 서울 리전(asia-northeast3)에 구성되어 있습니다. 다만 구독 검증과 계정 삭제 정리를 수행하는 Firebase Cloud Functions는 미국 리전(us-central1, Iowa)에서 실행되므로 해당 기능 수행에 필요한 개인정보가 미국에서 처리됩니다.

  • 이전받는 자: Google Cloud Platform (한국 계약 주체: Google Cloud Korea LLC, Google 계열사 및 승인된 하위처리자 포함). Google Cloud 개인정보 문의: Google Cloud 개인정보팀 (이메일: googlekrsupport@google.com, 등록 주소: Gangnam Finance Center 20fl., 152 Teheran-ro, Gangnam-gu, Seoul, South Korea)
  • 이전 국가: 미국(주 처리 리전: us-central1, Iowa). 서비스 운영·지원 과정에서 Google Cloud의 계약 및 하위처리자 정책에 따라 추가 국가에서 제한적으로 처리될 수 있습니다.
  • 이전 항목: Firebase UID와 인증 상태, App Check 관련 검증 정보, 구독 상품·거래 식별 및 계정 바인딩·검증 자료, 요청 상관관계 정보, 계정 삭제 요청 식별자와 삭제 처리에 필요한 계정 식별 정보
  • 이전 시기·방법: 이용자가 구매·복원·구독 자격 새로고침 또는 앱 내 계정 삭제를 요청할 때 암호화된 HTTPS/TLS 통신으로 전송되며, 계정 삭제 작업은 생성된 삭제 작업을 계기로 서버에서 처리됩니다.
  • 이용 목적: App Store 구독의 서버 검증과 Plus 자격 반영, 부정 이용 방지·백엔드 무결성 확인, 계정 및 연결 데이터 삭제 처리
  • 보유·이용 기간: Cloud Functions 요청 데이터는 기능 수행에 필요한 동안 처리되며, 처리 결과와 최소 상태·상관관계 정보는 별도 보유정책에 따라 관리됩니다. Google Cloud의 고객 데이터 처리기간은 서비스 계약 기간 및 계약 종료 후 Google Cloud 데이터 처리 부속약관에 따라 고객 데이터가 삭제될 때까지입니다. 운영·보안 로그는 Google Cloud의 적용 가능한 보존정책을 따릅니다.
  • 이전 거부: 이용자는 국외 처리가 필요한 구매·복원·자격 새로고침 기능을 사용하지 않는 방법으로 해당 처리를 거부할 수 있으며, 이 경우 Plus 구매 확인·복원 또는 자격 갱신이 제한될 수 있습니다. 계정 삭제 등 법정 권리행사와 관련하여 국외 처리를 원하지 않는 경우 support.runpet@gmail.com으로 문의할 수 있으며, 런토리는 가능한 대체 절차를 안내합니다.

Google Mobile Ads·UMP 또는 Apple 서비스가 이용자 기기에서 직접 수집·처리하는 정보는 본 조의 Cloud Functions 처리위탁과 구분되며, 각각 제4조·제5조 및 해당 제공자의 개인정보 처리 기준에 따라 처리됩니다.

제4조 (구독 검증)

iOS 구매·복원 시 StoreKit 거래 정보와 검증 자료가 Apple 및 Firebase HTTPS 검증 기능에서 처리됩니다. 서버 검증된 활성 또는 유예 상태에서만 지속 Plus 혜택을 반영합니다. 런토리 Plus 이용자에게는 배너 및 보상형 광고 요청이 차단됩니다.

제5조 (광고와 추적)

무료 이용자에게 Google Mobile Ads 배너와 보상형 광고가 표시될 수 있습니다. 광고 요청 전 Google UMP를 통해 동의 필요 여부를 확인하고, 필요한 경우 동의 화면을 표시합니다. 설정에서 광고 개인정보 옵션을 다시 열 수 있습니다.

현재 출시 광고 요청에는 비맞춤형 광고 신호와 제한적 데이터 처리 신호를 적용하고, iOS 광고 SDK의 게시자 자체 식별자를 비활성화합니다. ATT 권한을 요청하지 않으며 맞춤형 광고 또는 앱 간 추적을 활성화하지 않습니다.

비맞춤형·제한 광고도 광고 제공, 빈도 제한, 보고, 보안과 부정 사용 방지를 위해 IP 기반 대략적 위치, 앱·기기 식별 정보, 광고 데이터, 상품 상호작용과 SDK 진단 정보를 처리할 수 있습니다. 향후 맞춤형 광고, ATT, 미디에이션 또는 광고 파트너 구성이 변경되면 본 방침과 동의 절차를 다시 검토합니다. Firebase Analytics와 Crashlytics는 현재 활성화하지 않습니다.

제6조 (보유와 삭제)

원시 GPS 경로는 기기에서 최대 365일 보관할 수 있습니다. 이용자는 기록·사진 삭제, 위치 동의 철회, 로그아웃, 앱 내 계정 삭제를 수행할 수 있습니다. 계정 삭제는 Firebase Auth 계정, 원격 프로필·친구·구조화 백업, 계정별 경로·사진 Storage 자산과 로컬 소유자 데이터 정리를 요청합니다.

App Check 보안 자료, 광고 동의 정보와 광고 제공자의 집계 보고·보안 기록은 각 제공자의 보유 정책과 개인정보 설정을 따르며 런토리 계정 삭제만으로 제공자 수준 집계 기록이 모두 삭제된다고 보장할 수 없습니다. 앱 또는 런토리 계정 삭제는 App Store 구독을 자동 해지하지 않습니다.

제7조 (앱 권한과 설정)

  • 위치(사용 중/백그라운드): 활성 실외 러닝
  • 모션 및 피트니스: 실내 러닝·걸음 표시
  • 사진 라이브러리: 사용자가 선택한 기록 사진
  • Sign in with Apple: iOS 계정 인증
  • App Attest·DeviceCheck: 사용자 권한 팝업 없이 수행되는 백엔드 무결성 확인
  • UMP 광고 개인정보 옵션: 법적으로 필요한 광고 동의와 선택 관리

제8조 (미성년자)

런토리는 만 14세 이상을 대상으로 하며 만 14세 미만은 가입을 완료할 수 없습니다. 생년월일과 법정대리인 정보를 별도로 수집하는 절차는 제공하지 않습니다.

제10조 (처리방침 변경)

백업, 친구, 광고, 구독, 위치 또는 계정 처리 범위의 중요한 변경은 검토와 고지 후 적용합니다.
