최종 업데이트: 2026-07-12

개인정보 처리방침 이용약관 위치기반서비스 이용약관 고객 지원 계정 삭제 구독 안내

앱에서 계정 삭제

로그인한 사용자는 런토리 앱 설정 → 계정 삭제에서 전용 안내 화면을 통해 계정 삭제를 요청할 수 있습니다. 안내 내용을 확인·동의한 뒤에만 삭제가 시작됩니다.

삭제되는 데이터

  • Firebase Auth 계정 및 서버에 저장된 개인정보·관련 데이터
  • 계정 백업(Firestore/Storage)과 업로드된 러닝 경로·사진
  • 친구 코드·관계·관련 참조 데이터
  • 이 기기에 저장된 러닝 기록, 경로, 사진, 펫·챌린지 데이터

삭제되지 않거나 별도 관리되는 항목

  • App Store 구독 — 계정 삭제로 자동 취소되지 않습니다. 결제가 계속될 수 있으므로 삭제 전에 App Store에서 구독을 관리하세요.
  • 기기 사진 보관함 원본 — 앱이 기기 앨범의 원본 사진을 삭제하지 않습니다.
  • OS 위치 권한 — iPhone 설정 앱에서 직접 변경해야 합니다.
  • 구독 검증·부정사용 방지 거래 기록 — 보안·정산 목적으로 일정 기간 보관될 수 있습니다.

처리 시간

계정 삭제는 여러 단계(재인증, 서버 정리, 인증 계정 삭제, 기기 데이터 정리)로 진행됩니다. 완료되기 전에는 성공으로 표시되지 않으며, 실패 시 앱에서 다시 시도할 수 있습니다.
