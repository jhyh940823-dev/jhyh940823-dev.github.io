1. 目的

本規約は、멍스토어 が提供する RUNTORY の屋外 GPS ランニング、ルートのバックアップ・復元その他の位置情報サービスの利用条件と、個人位置情報に関する利用者の権利を定めます。

2. サービス内容

利用者が屋外ランニングを開始して GPS の準備が始まった時点から、RUNTORY は位置情報を利用してルート、距離、時間、ペースを計算します。画面ロック中または他のアプリを使用中でも、OS が許可する範囲で位置情報を利用する場合があります。屋内ランニングは位置情報なしで利用できます。

3. 個人位置情報の保存・バックアップ

生の GPS ルートは端末内に最大365日保存される場合があります。完了したランニングのルート座標は、ログイン中アカウント単位の圧縮アセットとして Firebase Storage にバックアップ・復元される場合があり、ポイント順序、緯度、経度、UTC 時刻が含まれる場合があります。

Firestore には保存先、ハッシュ、サイズ、形式、関連識別子など復元に必要なマニフェストが保存される場合があります。ルート情報はランニング記録および利用者が要求したバックアップ・復元を提供するために処理し、広告ターゲティングや第三者への販売には使用しません。

個人位置情報は、サービス提供目的の達成または利用者による削除・同意撤回後、別の法的保存根拠がある場合を除き、実質的な復元・再利用が困難となる方法で廃棄します。

4. 位置情報の収集・利用・提供事実確認記録

RUNTORY は韓国の位置情報法に基づき、位置情報の収集・利用事実を確認できる記録を自動的に作成・保存します。確認記録には、収集要求者、収集・利用時刻、収集方法、取得経路、利用方法などが含まれ、緯度・経度など実際の位置座標自体は含みません。

RUNTORY の確認記録の保存期間は記録日から6か月です。期間終了後に自動廃棄し、利用者が位置情報利用への同意を撤回した場合またはアカウントを削除した場合、別の法的保存根拠がない当該利用者の確認記録は6か月前でも速やかに廃棄します。

確認記録は現在安全なサーバー保存領域で管理します。サービス終了など運用上必要な場合は暗号化された別の保存媒体へ移管することがありますが、保存期間、アクセス制御、期間終了後の廃棄義務は同様に適用されます。

5. 個人位置情報に関する権利と行使方法

利用者はいつでも位置情報の収集・利用への同意の全部または一部を撤回し、収集・利用の一時停止を求めることができます。また、本人に関する位置情報の収集・利用・提供事実確認記録の閲覧・通知を求め、誤りがある場合は訂正を求めることができます。

権利行使は RUNTORY の設定 → データ管理、メール support.runpet@gmail.com、電話 010-2682-8230 から行えます。本人確認のため必要最小限の認証を求める場合があります。

6. 削除・同意撤回

利用者は個別のランニング記録を削除するか、設定から位置情報利用への同意を撤回できます。撤回時には関連する端末内の生ルート座標と、別の法的保存根拠がないサーバー側の位置利用事実確認記録を削除し、新しい屋外 GPS ランニングの開始を制限します。進行中のランニングでは記録の整合性のため終了後に撤回手続きを完了する場合があります。

アカウント削除時には Firebase Auth アカウント、リモートプロフィール・フレンド・構造化バックアップ、アカウント単位のルート・写真アセット、および当該アカウントの位置利用事実確認記録を整理します。一時的なネットワーク・サーバーエラーがある場合、完了まで安全な再試行状態が維持されることがあります。

7. 外部処理および第三者提供

Firebase Storage と Firestore はアカウント単位のルートのバックアップ・復元および位置利用事実確認記録の管理に使用し、Firebase Cloud Functions は確認記録の作成・削除と保存期間管理に使用します。処理委託・国外処理の詳細は プライバシーポリシー をご確認ください。

現在 RUNTORY は、個人位置情報を広告ターゲティングまたは販売目的で利用せず、個人位置情報を第三者へ提供する位置情報サービス機能を運営していません。将来そのような機能を導入する場合は、法令上必要な同意・通知手続きを事前に適用します。

9. 利用上の限界

RUNTORY は14歳以上の方のみ利用できます。GPS とセンサーの結果は端末、ネットワーク、周辺環境により不正確、遅延、または消失することがあります。RUNTORY は医療、緊急救助、ナビゲーションサービスではありません。
