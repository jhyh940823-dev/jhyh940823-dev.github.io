1. サービス

RUNTORY は、利用者が明示的に開始した屋外ランニング中に GPS を使用し、経路・距離・時間・ペースを計算します。画面ロック中または他のアプリを使用中でも、OS が許可する範囲で位置情報を使用することがあります。屋内ランニングは位置情報なしで利用できます。

2. 保存・バックアップ・復元

生の GPS 経路は端末内に最大 365 日間保存されることがあります。完了したランニングの経路座標は、ログイン中の Firebase アカウント単位の圧縮アセットとして Firebase Storage にバックアップ・復元されることがあります。経路アセットには、ポイント順序、緯度、経度、UTC 時刻が含まれることがあります。

Firestore には保存先、ハッシュ、サイズ、形式、関連識別子など、復元に必要なマニフェストが保存されることがあります。公開ダウンロード URL や端末上のローカル絶対パスはリモートマニフェストに保存しません。生成されたオーバーレイ、結果画像、地図スナップショット、共有用エクスポートファイルは現在の経路バックアップ対象ではありません。

経路データは利用者が要求したアカウントのバックアップ・復元機能を提供するために処理され、広告目的または第三者への販売目的では提供されません。

3. 削除・同意撤回

利用者は個別の記録を削除するか、設定で位置情報利用への同意を撤回できます。撤回すると端末に保存された生の経路座標を削除し、新しい屋外 GPS ランニングの開始を制限します。記録の完全性と安全のため、進行中のランニングでは撤回が制限されることがあり、終了後に撤回できます。

アカウント削除時には、Firebase Auth アカウント、リモートプロフィール、友だちデータ、構造化バックアップ、アカウント単位の Firebase Storage 経路アセットの削除を要求します。一時的なネットワークまたはサーバーエラーが発生した場合、安全な再試行状態が維持されることがあります。距離・時間・ペースなどの要約は別途削除されるまで維持されることがあります。

4. 外部処理

Firebase Storage と Firestore は、アカウント単位の経路バックアップ・復元に使用されます。Apple、Firebase その他のサービス提供者による処理は、プライバシーポリシーおよび各提供者のポリシーに従います。RUNTORY は正確な経路データを医療、緊急救助、ナビゲーション、広告ターゲティング目的には使用しません。

6. 利用上の限界

RUNTORY は 14 歳以上の方のみ利用できます。GPS とセンサーの結果は、端末、ネットワーク、周辺環境により不正確、遅延、または消失することがあります。RUNTORY は医療、緊急救助、ナビゲーションサービスではありません。
