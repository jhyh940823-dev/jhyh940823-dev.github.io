1. 利用目的

RUNTORY は、ランニング記録、ペット育成、フレンド、アカウントのバックアップ・復元、iOS サブスクリプション、無料利用者向け広告、バックエンド保護を提供するために必要な情報を処理します。商用 iOS リリースは Firebase Auth、Sign in with Apple、Firebase App Check、Google UMP、Google Mobile Ads を使用します。

2. 処理する情報

  • Firebase UID、ログイン提供者情報、提供される場合のメール・プロフィール情報
  • 表示名、フレンドコード、申請、関係、一覧、ランキング要約
  • 14歳以上の確認、必須同意のバージョン・時刻
  • App Attest、DeviceCheck、App Check によるアプリ・端末の整合性情報
  • 精密位置、完了ランの GPS ルート座標、距離、時間、ペース、モーション、歩数
  • 利用者が選択したアプリ管理のオリジナル記録写真
  • ペット、卵、チャレンジ、インベントリ、バッジ、設定、構造化バックアップ
  • iOS サブスク商品、取引検証情報、資格状態、最小限の取引相関情報
  • 広告同意状態、および広告配信で処理される場合がある IP 由来のおおよその位置、アプリ・端末識別情報、広告データ、製品操作、SDK 診断情報

RUNTORY はカード番号や銀行口座情報を直接収集・保存しません。

3. 保存と外部処理

アプリデータは端末内の Drift/SQLite、SharedPreferences、アプリ文書領域に保存されます。Firebase Auth はログイン、Firebase App Check はアプリ・端末の整合性、Firestore はアカウント・プロフィール・フレンド・構造化バックアップと非公開資格、Firebase Storage は所有者別の完了ルートとオリジナル写真、Cloud Functions はサブスク検証とアカウント削除に使用されます。Apple はログイン、証明、App Store 決済を処理します。

完了したルートとアプリ管理のオリジナル記録写真は所有者別 Firebase Storage にバックアップされる場合があります。Firestore には復元用マニフェストを保存し、公開ダウンロード URL、端末の絶対パス、生の座標配列、画像バイトは直接保存しません。生成したオーバーレイ・結果画像、地図スナップショット、共有用エクスポートは現在のバックアップ対象外です。

国外での処理委託

RUNTORY の Firestore データベースと利用者バックアップ用 Firebase Storage は韓国・ソウル（asia-northeast3）に構成されています。一方、サブスクリプション検証とアカウント削除処理に使用する Firebase Cloud Functions は米国（us-central1、Iowa）で実行されるため、これらの機能に必要な個人情報は米国で処理されます。

  • 受領者・処理者: Google Cloud Platform（韓国の契約主体: Google Cloud Korea LLC。Google の関連会社および承認済みサブプロセッサを含む）。プライバシー窓口: Google Cloud プライバシーチーム（メール: googlekrsupport@google.com、登録住所: Gangnam Finance Center 20fl., 152 Teheran-ro, Gangnam-gu, Seoul, South Korea）
  • 国: 米国（主処理リージョン: us-central1、Iowa）。サービス運用・サポートのため、Google Cloud の契約・サブプロセッサ条件に基づき追加の国で限定的に処理される場合があります。
  • データ: Firebase UID・認証状態、App Check 検証情報、サブスク商品・取引識別子、アカウント紐付け・検証資料、リクエスト相関情報、削除リクエスト識別子、削除処理に必要なアカウント識別情報
  • 時期・方法: 購入、復元、資格更新、アプリ内アカウント削除の実行時に暗号化された HTTPS/TLS で送信され、削除ジョブ作成時にはサーバーワーカーでも処理されます。
  • 目的: App Store サブスクのサーバー検証と Plus 資格反映、不正利用・整合性保護、アカウントおよび関連データの削除
  • 保存期間: Cloud Functions のリクエストデータは機能実行に必要な期間処理され、結果・最小限の状態／相関情報は RUNTORY の保存方針に従います。Google Cloud Data Processing Addendum に基づく顧客データ処理はサービス契約期間および契約終了後に顧客データが削除されるまで行われ、運用・セキュリティログは適用される Google Cloud の保存方針に従います。
  • 拒否: この国外処理が必要な購入・復元・資格更新を利用しないことで拒否できますが、Plus の検証・復元・更新が利用できない場合があります。アカウント削除など法定の権利行使でこの国外経路を希望しない場合は support.runpet@gmail.com へ連絡し、利用可能な代替手続きを確認してください。

Google Mobile Ads/UMP または Apple サービスが利用者端末から直接収集・処理する情報は、この Cloud Functions の国外処理委託とは区別され、第4条・第5条および各提供者のプライバシー条件に従います。

4. サブスクリプション検証

iOS の購入・復元では、StoreKit の取引・検証情報が Apple と Firebase HTTPS 検証機能で処理されます。サーバー検証済みの有効または猶予状態でのみ継続的な Plus 特典を反映します。RUNTORY Plus 利用者については、バナー広告とリワード広告のリクエストを停止します。

5. 広告と追跡

無料利用者には Google Mobile Ads のバナー広告とリワード広告が表示される場合があります。広告リクエスト前に Google UMP で同意要否を確認し、必要な場合は同意フォームを表示します。プロバイダが必要とする場合、設定から広告プライバシーオプションを開けます。

リリース時の広告リクエストには非パーソナライズ広告と制限付きデータ処理のシグナルを適用し、iOS 広告 SDK のパブリッシャー・ファーストパーティ ID を無効化します。ATT を要求せず、パーソナライズ広告やアプリ横断追跡を有効化しません。

制限付き・非パーソナライズ広告でも、配信、頻度制限、レポート、セキュリティ、不正防止のため、IP 由来のおおよその位置、アプリ・端末識別情報、広告データ、製品操作、SDK 診断情報を処理する場合があります。パーソナライズ広告、ATT、メディエーション、広告パートナーを変更する場合は、本方針と同意手順を再確認します。Firebase Analytics と Crashlytics は現在有効化していません。

6. 保存期間と削除

生の GPS ルートは端末で最大365日保存される場合があります。利用者は記録・写真削除、位置同意撤回、ログアウト、アプリ内アカウント削除を行えます。アカウント削除は Firebase Auth、リモートプロフィール・フレンド・構造化バックアップ、所有者別ルート・写真 Storage 資産、ローカル所有者データの削除を要求します。

App Check セキュリティ資料、広告同意記録、広告提供者の集計レポート・セキュリティ記録は各提供者の保存方針とプライバシー設定に従います。RUNTORY アカウント削除だけで提供者レベルの集計記録がすべて削除されるとは限りません。アプリまたは RUNTORY アカウントを削除しても App Store サブスクリプションは解約されません。

7. アプリ権限と機能

  • 位置情報（使用中・バックグラウンド）: アクティブな屋外ラン
  • モーションとフィットネス: 屋内ラン・歩数表示
  • 写真ライブラリ: 利用者が選択した記録写真
  • Sign in with Apple: iOS 認証
  • App Attest/DeviceCheck: 利用者向け権限表示なしのバックエンド整合性確認
  • UMP プライバシーオプション: 法令上必要な広告同意と選択管理
  • ATT: リリース版では要求しません

8. 未成年者

RUNTORY は14歳以上を対象とし、14歳未満は登録を完了できません。生年月日や法定代理人情報を別途収集する手続きは提供しません。
