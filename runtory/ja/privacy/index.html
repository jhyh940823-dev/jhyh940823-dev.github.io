1. 利用目的

RUNTORY は、ランニング記録、ペット育成、フレンド、アカウントのバックアップ・復元、iOS サブスクリプション、無料利用者向け広告、位置情報サービス、バックエンドの安全性を提供するために必要な個人情報を処理します。

2. 処理する情報

  • Firebase UID、ログイン提供者情報、提供される場合のメール・プロフィール情報
  • 表示名、フレンドコード、申請、関係、一覧、ランキング要約
  • 14歳以上の確認、必須同意のバージョン・時刻
  • App Attest、DeviceCheck、Firebase App Check に関するアプリ・端末の整合性情報
  • 屋外ラン中の精密位置、完了ランの GPS ルート座標、距離、時間、ペース、モーション、歩数
  • 位置情報の収集・利用事実確認記録（収集要求者、収集・利用時刻、収集方法、取得経路、利用方法など）。確認記録自体には緯度・経度の実位置座標を含めません
  • 利用者が選択したアプリ管理のオリジナル記録写真
  • ペット、卵、チャレンジ、インベントリ、バッジ、設定、構造化バックアップ
  • iOS サブスク商品、ハッシュ化された購入・利用者識別値、検証状態・時刻、満了・解約・返金に関する時刻、最小限の取引相関情報
  • 広告同意状態、および広告配信で処理される場合がある IP 由来のおおよその位置、アプリ・端末識別情報、広告データ、製品操作、SDK 診断情報

RUNTORY はカード番号や銀行口座情報を直接収集・保存しません。

3. 保存、処理委託、国外処理

アプリデータは端末内の Drift/SQLite、SharedPreferences、アプリ文書領域に保存される場合があります。Firebase Auth はログイン、Firebase App Check はアプリ・端末の整合性、Firestore はアカウント・プロフィール・フレンド・構造化バックアップ、サブスク検証台帳、位置利用事実確認記録、Firebase Storage は所有者別の完了ルートとオリジナル写真、Cloud Functions はサブスク検証、位置利用事実確認記録の処理、アカウント削除、保存期間満了データの整理に使用されます。

処理委託: RUNTORY はサービス提供に必要な範囲で、Google Cloud/Firebase に認証、データベース、ストレージ、サーバー関数、アプリ整合性確認および関連インフラ運用を委託します。委託業務またはサービス関係の終了後は、RUNTORY の保存・廃棄方針および Google Cloud の契約上の削除手続に従って処理します。

Firestore データベースと利用者バックアップ用 Firebase Storage は韓国・ソウル（asia-northeast3）に構成されています。サブスク検証、位置利用事実確認記録の処理、アカウント削除、保存期間管理に使用する Firebase Cloud Functions は米国（us-central1、Iowa）で実行されるため、必要な情報が米国で処理される場合があります。

  • 処理者: Google Cloud Platform（Google Cloud Korea LLC、Google 関連会社、承認済みサブプロセッサを含む）
  • 国: 米国（主処理リージョン us-central1、Iowa）および Google Cloud の契約・サブプロセッサ条件で認められる限定的な追加地域
  • 時期・方法: 購入・復元・資格更新、屋外位置利用事実の送信、アカウント削除などの機能利用時に暗号化された HTTPS/TLS で処理
  • 目的: App Store サブスクのサーバー検証、位置利用事実の安全な記録、不正利用・整合性保護、アカウント整理、保存期間管理

Apple のログイン・App Store 決済、および Google Mobile Ads/UMP が利用者端末で直接処理する情報は、各提供者のサービス・プライバシー条件に従います。

4. サブスクリプション検証

iOS の購入・復元では、StoreKit の取引・検証情報が Apple と RUNTORY の Firebase HTTPS 検証機能で処理されます。サーバー検証済みの状態に応じて Plus 資格を反映し、RUNTORY Plus 利用者についてはバナー広告とリワード広告のリクエストを停止します。

5. 広告と追跡

無料利用者には Google Mobile Ads のバナー広告とリワード広告が表示される場合があります。広告リクエスト前に Google UMP で同意要否を確認し、必要な場合は同意フォームを表示します。

現在のリリース構成では非パーソナライズ広告・制限付きデータ処理シグナルを使用し、iOS 広告 SDK のパブリッシャー・ファーストパーティ ID を無効化します。ATT を要求せず、パーソナライズ広告やアプリ横断追跡を有効化しません。Firebase Analytics と Crashlytics は現在有効化していません。

6. 保存期間、廃棄手続および方法

  • 生の GPS ルート: 端末で最大365日。利用者が記録を削除するか位置同意を撤回した場合、関連する生のルート情報を削除します。
  • アカウント・プロフィール・フレンド・バックアップ・ルート・写真: サービス／アカウント提供に必要な期間保存し、対象データまたはアカウントの削除時に関連するサーバー・端末データを整理します。
  • 位置情報の収集・利用事実確認記録: 韓国の位置情報法に基づき自動記録・保存し、RUNTORY の運用方針として記録日から6か月保存します。位置同意の撤回またはアカウント削除時、別の法的保存根拠がない当該利用者の確認記録は6か月前でも速やかに廃棄します。
  • 最小限のサブスク取引・検証台帳: 法令上必要な電子商取引記録および精算・紛争対応のため、最終検証・処理日から5年間保存後に廃棄します。ハッシュ化された購入・利用者識別値、商品・プラン、検証状態・時刻、満了・解約・返金に関する時刻、最小限の相関情報のみを保存し、カード番号・銀行口座情報は保存しません。

保存期間終了または処理目的達成後、電子データは実質的な復元・再利用が困難となる方法で削除します。法令上保存が必要な記録は通常のサービスデータと分離してアクセスを制限し、該当期間終了後に廃棄します。

法定保存記録の保管媒体は運用上の必要に応じて変更される場合があります。例えばサービス終了時に Firebase から暗号化された別媒体へ移管することがありますが、残存保存期間、アクセス制御、期間終了後の廃棄義務は同様に適用されます。

RUNTORY アプリまたはアカウントを削除しても App Store サブスクリプションは自動解約されません。
